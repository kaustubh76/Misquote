Why no third-party agents appear here

This site indexes the ERC-8004 registry and lists what it finds on the registry page. None of those agents declares a category — not on its card, not in the survey, nowhere in the standard. Sorting them into these means reading strangers’ free-text descriptions and deciding on their behalf what they are for, and the result is our classification of their words.

So it is shown as ours. Each category page lists the agents an index holds for it and prints, on every row, the term that row had to contain to appear — the judgement is on the page rather than behind it. None of them carries a quote, because we do not have their policies.

One agent per category is a fact, not a design

Each of these holds exactly one agent today because exactly one was built for it. The pages below are shaped for more, and a second arrival would appear beside the first rather than replacing it.
