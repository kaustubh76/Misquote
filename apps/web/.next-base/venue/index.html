Where PancakeSwap is not Uniswap

The cores are the same source. Everything below is a place they diverge, and each one is a defect this project hit before it was a paragraph.

The math is Uniswap's

PancakeSwap v3 forks Uniswap v3, so the tick and liquidity libraries are the same source. That is what makes a differential corpus meaningful rather than circular.

Where it is not

Each row cost something before it was written down. The last column is what catches it now.

The protocol takes 34% of every fee, by default

Uniswap v3

protocol fee off unless governance turns it on

PancakeSwap v3

slot0.feeProtocol packs (fee0, fee1); this pool reads 3400, so LPs keep 66%

Reconstructing fees from swap volume — the natural way to write a replay engine — overstates LP earnings by 1.515x, and that error lands on the headline APR.

packages/misquote/core/fees.py · caught by tests/core/test_fees.py · P-1, P-8: no constant is right for both of our pools

Pools are deployed by a separate PancakeV3PoolDeployer

Uniswap v3

CREATE2 from the factory, address derivable offline

PancakeSwap v3

a different init-code hash, so Uniswap's computeAddress constants are wrong

Deriving a pool address offline produces a plausible address that is not the pool. Resolve through factory.getPool(), always.

packages/misquote/chain/nfpm.py · caught by packages/misquote/vetting/badge.py — check 'factory resolves it' · P-6

The callbacks are renamed

Uniswap v3

uniswapV3MintCallback

PancakeSwap v3

pancakeV3MintCallback

A direct pool call built against the Uniswap ABI reverts. Everything here goes through the position manager instead, never the pool.

packages/misquote/chain/nfpm.py · caught by tests/chain/test_write_path.py · P-6

The router keeps `deadline` inside the params struct

Uniswap v3

SwapRouter02 dropped it from the struct

PancakeSwap v3

it is still a member, so the calldata shape differs

The wrong shape costs 23,000 gas and reverts with empty data, which looks like nothing at all. Check the selector, not the documentation.

packages/misquote/chain/nfpm.py · caught by tests/chain/test_position_differential.py · P-6

There is no 3000 fee tier, and so no spacing of 60

Uniswap v3

3000 -> 60 is the most-used tier

PancakeSwap v3

100 -> 1 · 500 -> 10 · 2500 -> 50 · 10000 -> 200

A width copied from a Uniswap example assumes a spacing that does not exist. And MIN_TICK is not a multiple of any of these — 887272 % 10 = 2 — so clamping a bound to the extreme yields a tick the pool refuses and the mint reverts.

packages/misquote/core/policy.py · caught by packages/misquote/vetting/badge.py — check 'a mintable range exists' · P-6, V-10

The Swap event is not Uniswap's

Uniswap v3

seven parameters; topic0 0xc42079f9…

PancakeSwap v3

nine — it carries protocolFeesToken0 and protocolFeesToken1; topic0 0x19b47279…

Filtering on the Uniswap signature returns zero logs from a pool doing millions in volume. The two extra fields are also why the accountant reads the protocol's actual take per swap rather than modelling it.

packages/misquote/indexer/reader.py · caught by packages/misquote/lvr/accountant.py · P-1

The pool charges one fee. The LP is not paid all of it, and a replay written from Uniswap v3’s documentation has no reason to know that.

the LP receives 66.0% — feeProtocol 3,400the protocol takes 34.0%

1.515× — how much a replay that reconstructs fees from swap volume overstates what a position earned, and it lands on the headline return.
